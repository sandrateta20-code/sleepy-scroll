# The Sleepy Scroll v2

**An Open Android Research Framework and a Simulation-Validated Protocol for Passive Sleepiness Estimation**

Teta Sandra · Bera Kaliza Lisa — Department of Artificial Intelligence, Kyungdong University

📄 **[Read the paper (PDF)](The_Sleepy_Scroll_v2.pdf)**

## Abstract
Late-night smartphone sessions often run past the time people intend to go to bed, yet screen-time tools react to fixed limits rather than to how the user is behaving. The Sleepy Scroll is a consent-based framework that estimates self-reported sleepiness (Karolinska Sleepiness Scale) from scrolling and touch timing inside a controlled Android feed and offers an optional, dismissible wind-down interface. This version contributes an open Android research application, a shared analysis pipeline, and a pre-data simulation study that exercises the complete evaluation protocol on 50 simulated participants.

> All results in the paper come from simulated data and test the evaluation protocol, not the hypothesis itself.
